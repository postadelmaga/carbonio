How it works. Messages are read before they appear: this is not censorship, it is how the spam is kept out, and a blunt criticism will be published exactly as it was written. No sign-up and no cookies. Your IP address is not stored: a salted fingerprint of it is, which disappears after a month for messages and lasts as long as the vote for votes, because it is the only thing stopping a second vote. One answer per question per section: changing your mind replaces the previous one, it does not add a second.

If you have a GitHub account and the report is technical, an issue is easier for both of us: it can be discussed and closed.
