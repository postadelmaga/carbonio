Qué opináis

Esta página lleva años corrigiéndose gracias a quien la lee. Aquí es donde se escribe: un error encontrado, una fuente mejor, un gráfico que no se entiende, o simplemente que ha servido.

Deja un mensaje

Cómo funciona. Los mensajes se leen antes de aparecer: no es censura, es la manera de dejar fuera el spam, y quien escriba una crítica seca la verá publicada tal cual. No hace falta registrarse, no hay cookies y la dirección IP no se conserva: se guarda una huella durante un mes, solo para contarte una vez.

Si tienes cuenta de GitHub y el aviso es técnico, una issue es más cómoda para los dos: se puede discutir y cerrar.
