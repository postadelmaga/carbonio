留个言

运作方式。留言会先被阅读再显示：这不是审查，而是把垃圾信息挡在外面的办法；尖锐的批评会原样发表。无需注册，也没有 Cookie。IP 地址不会被保存：保存的是它加盐后的指纹，留言的指纹一个月后删除，投票的指纹与投票同在，因为它是唯一能阻止重复投票的东西。每一节的每个问题只能回答一次：改变想法会替换掉之前的答案，而不是再加一票。

如果你有 GitHub 账号，而且问题偏技术性，提一个 issue 对双方都更方便：可以讨论，也可以关闭。
